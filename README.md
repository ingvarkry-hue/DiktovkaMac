# DiktovkaMac

Русский голосовой ввод в **любое** окно на Mac: браузер, Telegram, Kimi, Word, почта.
Речь распознаётся **локально** — нейросетью Whisper (faster-whisper) прямо на вашем компьютере,
ничего не уходит в облако. Нажали клавишу — говорите — нажали ещё раз — готовый текст
вставлен туда, где стоит курсор.

Пока идёт распознавание, внизу экрана по центру крутится розовый шарик — видно, что речь
преобразуется. Закончил — шарик гаснет, текст на месте.

## Требования

- macOS 13 Ventura или новее
- Apple Silicon (M1/M2/M3/M4) или Intel
- Python 3.10+ (`brew install python3`)
- Интернет нужен только один раз — при установке (модель ~1,6 ГБ)

## Установка

```bash
git clone <ссылка-на-репозиторий> DiktovkaMac
cd DiktovkaMac
./install.sh
```

Установщик создаст виртуальное окружение, поставит библиотеки, скачает модель,
соберёт `DiktovkaMac.app` и запустит его. Займёт 5–15 минут, зависит от интернета.

Вся установка живёт в одной папке — систему не трогает.

### Первый запуск — два разрешения

1. **Микрофон** — macOS спросит при первой записи, разрешите.
2. **Универсальный доступ** (нужен для вставки текста и горячей клавиши):
   Системные настройки → Конфиденциальность и безопасность → Универсальный доступ →
   включите **python3.x** в списке (программа называется именно так, это нормально).
   Если включали до запуска — выключите и включите снова, иначе tap не оживёт.

## Как пользоваться

1. Поставьте курсор в поле ввода.
2. Нажмите **英数** (eisu) — клавиша слева от пробела на японской JIS-клавиатуре —
   внизу экрана появится розовый шарик.
3. Говорите.
4. Нажмите клавишу ещё раз — шарик погаснет, а через пару секунд текст окажется в поле ввода.

Работает в любом приложении: мессенджеры, браузер, редакторы, почта.

## Горячая клавиша

По умолчанию — **eisu** (英数). Другие варианты в `config.json`:

| Значение | Клавиша |
| --- | --- |
| `"eisu"` | 英数, слева от пробела (JIS-клавиатуры) |
| `"kana"` | かな, справа от пробела (JIS-клавиатуры) |
| `"alt+space"` | Option + Пробел |
| `"cmd+shift+d"` | любая комбинация модификаторов + буква |

**Почему не F8, как в Windows-версии?** На Mac клавиши F7–F12 — медиа-клавиши,
до программ они не доходят. Поэтому по умолчанию — eisu/kana или комбинация с модификаторами.

## Настройки — `config.json`

| Параметр | Что делает |
| --- | --- |
| `hotkey` | клавиша записи (см. таблицу выше) |
| `model` | `"large-v3-turbo"` (лучше) или `"small"` (быстрее, чуть хуже качество) |
| `device` | `"auto"` — на Mac выберет чип Apple (MPS) или процессор |
| `language` | язык речи, `"ru"` по умолчанию |
| `beep` | `true` — звук при старте и остановке записи |
| `auto_send` | `true` — после вставки сразу нажимать Return (отправлять сообщение) |
| `prompt` | подсказка для Whisper (стиль пунктуации) |

После правки: выход через значок микрофона в меню-баре и `open DiktovkaMac.app` снова.

## Если что-то не так

- **Ничего не происходит по клавише** — проверьте значок 🎙 в меню-баре; нет значка —
  запустите `open DiktovkaMac.app`. Также проверьте «Универсальный доступ» (см. выше).
- **Шарик есть, текста нет** — откройте `DiktovkaMac.log` в папке программы, там есть диагноз.
- **Очень медленно** — в `config.json` поставьте `"model": "small"`.

## Удаление

Удалите папку программы — больше ничего в системе она не оставляла.
Значок в меню-баре исчезнет после выхода (правый клик → «Выход») или перезагрузки.
